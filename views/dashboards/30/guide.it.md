# Backup schede dati {#top}

Scarica i dati di ogni scheda (volontari, mezzi, servizi, richieste…) in un file, uno per
scheda. Si apre da *Configurazione → Backup schede dati*.

È la copia più semplice da fare e da conservare: non richiede nessuna conoscenza del
server. Per una copia unica di tutto il database e delle configurazioni vedi invece il
[Backup applicazione](guide:dashboards/31).

## Come si usa {#come}

La pagina ha un pulsante **BACKUP** per ogni scheda che contiene almeno un record (le
schede vuote non compaiono). Premi quello della scheda che vuoi salvare: il browser
scarica un file con il nome della scheda e la data di oggi.

Il file contiene tutti i record e tutte le colonne della scheda, nel formato di
esportazione di Camila.

Per salvare tutto l'evento ripeti l'operazione per ciascuna scheda: sono molte e non
c'è un pulsante «scarica tutto». Se ti serve una copia unica, usa il [Backup
applicazione](guide:dashboards/31).

## Quando farlo {#quando}

- a fine giornata, per le schede che cambiano di più (volontari, mezzi, richieste,
  brogliaccio);
- prima di un'operazione che modifica molti record, per esempio un'importazione;
- a fine evento.

I file scaricati contengono dati personali: conservali dove possono vederli solo le
persone autorizzate.
