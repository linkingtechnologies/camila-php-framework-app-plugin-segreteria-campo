# H. Corrispondenza con il vecchio manuale {#top}

Il vecchio manuale era organizzato per schede dati e per procedure (P01–P24). Questa tabella dice
dove si trova ora ciascuna parte. Dove la procedura è stata sostituita da una pagina del programma,
la guida di quella pagina è il riferimento.

| Vecchio manuale | Dove è ora |

| Preparazione applicativo: avvio, utenti, dati di esempio | [Primi passi](guide:manuale/02-primi-passi), [Preparare l'evento](guide:manuale/03-preparare) |
| Operazioni preliminari (preaccreditamenti, database, moduli, dati intervento, servizi) | [Preparare l'evento](guide:manuale/03-preparare) |
| Nozioni di base: struttura delle pagine, tabelle dati, funzionalità | [Le schede dati](guide:manuale/A-schede-dati) |
| Gestione evento (check-in, stato, check-out, gestione operativa, servizi) | [Accreditare](guide:manuale/04-accreditare), [Gestire](guide:manuale/05-gestire), [Chiudere](guide:manuale/08-chiudere) e le guide delle pagine |
